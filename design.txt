── EDUCATION ──────────────────────────────────────────────────────
  Layout: Vertical card stack (similar to Work timeline but with academic icons)
  Each card:
    - Graduation cap icon
    - Degree title (bold, font-display)
    - Institution name (accent color)
    - Period + Location meta (muted icons)
    - Description / highlights
    - GPA or honors badge (optional pill)
  Animation: Staggered fade-in from left/right, glass-card hover effect
  Design match: Reuse .glass-card, .section-label, .section-title patterns

── PROJECTS ───────────────────────────────────────────────────────
  Layout: 2-column responsive grid of project cards
  Each card:
    - Gradient top-border accent strip (3px)
    - Project title + short description
    - Tech stack tags (pills)
    - Action links: GitHub icon + Live Demo icon (bottom-right)
    - Hover: lift effect + glow shadow + border-accent
  Featured project: First card spans full width with larger layout
  Animation: Scale-in on scroll with staggered delays

── CONTACT ────────────────────────────────────────────────────────
  Layout: 2-column — left info + right form
  Left side:
    - Section header with gradient text
    - "Let's build something together" tagline
    - 3 info items: email, location, phone (icon + text in glass-cards)
    - Social links row
  Right side:
    - Glass-card form with inputs: Name, Email, Subject, Message
    - Input styling: dark bg, subtle border, focus glow (accent-primary)
    - Submit button: gradient-accent, hover lift + glow
  Animation: Slide-in from left/right on scroll

── FOOTER ─────────────────────────────────────────────────────────

=====================================================================
                       DESIGN PRINCIPLES
=====================================================================
  - All sections use same spacing tokens (--section-padding)
  - All interactive cards use .glass-card base class
  - framer-motion whileInView for scroll-triggered animations
  - react-scroll Link for smooth nav scrolling
  - BEM naming convention: component__element--modifier
  - Mobile-first responsive at 900px and 600px breakpoints
  - Consistent stagger delays: 0.15s between sibling items
